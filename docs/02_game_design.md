# 🎮 Game Design

## 🧭 Game Type

- Isometric (2.5D)
- Adventure + Strategy
- Single Player vs AI (MVP)

---

## 🌍 World

- Stylized fantasy environment
- Paths, trees, cliffs, villages
- No visible grid

---

## 🎯 Objective

- Reach goal (shrine / destination)
  OR
- Survive AI interference and complete objectives

---

## 🎮 Core Loop

1. Player explores world
2. Collects resources and abilities
3. AI interferes (traps, enemies, effects)
4. Player adapts
5. Outcome depends on strategy + decisions

---

## 💡 Game Feel

- Calm → tension → chaos → resolution
