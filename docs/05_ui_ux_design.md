# 🎨 UI/UX Design

## 🎯 Style

- Isometric stylized world
- Cozy fantasy environment
- Soft lighting and depth

---

## 🌍 World

- Grass, trees, paths, ruins
- Natural terrain
- No visible grid

---

## 🧭 Layout

### Top Right

- Mini map

### Top Left

- Player info (health, resources)

### Right Side

- Objectives

### Bottom

- Controls and actions

---

## 🎨 Design Principles

- Minimal UI
- World-first design
- Soft colors
- Smooth animations

---

## 🚫 Avoid

- Boxy UI
- Neon cyberpunk
- Flat layouts
