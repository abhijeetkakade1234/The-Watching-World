# 🚀 MVP Plan

## 🎯 Goal

Build a playable prototype with:

- movement
- basic world
- AI interaction

---

## 🧱 Features

- Isometric map
- Player movement
- One AI behavior (trap placement)
- One objective
- Basic UI

---

## ⏳ Steps

### Step 1

- Render map
- Add player

### Step 2

- Movement system

### Step 3

- AI trap system

### Step 4

- Objective + win condition

---

## 🚫 Excluded

- Multiplayer
- Advanced AI
- Complex combat
